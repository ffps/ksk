# ksk — киоск для старого планшета/телефона

Полноэкранный браузер (WebView) для Android 4.2+, без root.

## Возможности
- Автозапуск при загрузке системы.
- Если страница недоступна — N попыток с паузой P секунд (N = 0 — без ограничений).
- Адрес страницы, число попыток, пауза и расписание перезагрузки задаются в настройках.
- Автоперезагрузка: crontab из 5 полей (`*/30 * * * *`, `0 4 * * *`) или просто число минут.
- Экран не гаснет и не затемняется, показывается поверх экрана блокировки.

## Как попасть в настройки
- долго нажать (удерживать палец) на экране, или
- кнопка «Меню» (если есть), или
- настройки откроются сами при первом запуске, пока не задан адрес.

## Сборка
Каждый push запускает GitHub Actions. Готовый APK: вкладка **Actions** → последний запуск → **Artifacts** → `ksk-apk`.

## Установка и настройка устройства
1. Скопировать `app-debug.apk` на устройство и установить (разрешить установку из неизвестных источников).
2. **Один раз запустить приложение вручную** — иначе Android не доставит ему сигнал о загрузке системы.
3. Задать адрес страницы в настройках.
4. В настройках Android: блокировка экрана — «Нет»; по желанию в «Для разработчиков» включить «Не выключать экран» при зарядке.
5. По желанию: нажать кнопку Home и выбрать «Киоск» как приложение по умолчанию — тогда Home будет возвращать в киоск.
